# CloudBrowser v0.2 baseline approval

- Baseline: `v0.2.0`
- Decision: approved for test-first implementation
- Date: 2026-09-01
- Scope: product boundaries, Credential Broker security model, status-only
  broker intent, restricted agent control, exact-origin site declarations,
  owner/profile binding, revocation, MFA handoff, application identity
  verification, migration controls
- Not approved: live deployment, credential rotation, production release, or
  any mutation of the existing fleet

The baseline is immutable. Changes require a new proposal and a new baseline
identifier.
